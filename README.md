# React Interview Practice

一个基于 React 和 Vite 的轻量练习项目，适合用于熟悉 React 基础并在面试中演示。

## 开发环境

- Node.js `22.23.2`
- React `19`
- Vite `8`
- Oxlint

## 常用命令

```bash
npm install
npm run dev
npm run build
npm run lint
```

启动开发服务器后，Vite 会输出本地访问地址（通常是 `http://localhost:5173`）。

## 本项目包含

- 可复用的主题清单渲染
- 使用 `useState` 的完成状态切换
- 使用 `useMemo` 的进度派生计算
- 基础键盘可访问性与响应式样式

## 可继续练习

1. 把清单保存到 `localStorage`。
2. 添加“全部 / 已完成 / 未完成”筛选。
3. 将每个主题提取成独立组件。
4. 为交互添加单元测试。
